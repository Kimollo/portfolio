# Kimollo Hlakola — Portfolio

Personal software developer portfolio for [Kimollo Hlakola](https://github.com/Kimollo).

**Live:** https://portfolio-kimollo.vercel.app  
**Stack:** Vite · React · TypeScript · Tailwind CSS

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # typecheck + production build
npm run lint     # oxlint
npm run preview  # serve dist/
```

## Content

Site copy and links live in `src/data/`. Media assets are in `public/` (portrait, CV, project screenshots).
